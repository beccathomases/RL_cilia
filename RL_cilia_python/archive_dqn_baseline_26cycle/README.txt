Archived baseline DQN run for the small discrete 2-ball cilia benchmark.

This is the DQN run that produced the nearby length-26 cycle with slightly higher
average reward per period than the gamma = 0.99 value-iteration cycle. However,
exact comparison with the VI value function showed that the DQN policy remained
suboptimal for the discounted control problem.

This archive is kept as a fixed reference point before beginning broader DQN
hyperparameter sweeps and further exploratory experiments.
